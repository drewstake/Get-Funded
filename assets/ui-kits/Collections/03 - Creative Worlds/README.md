Preview set 2. All artwork is exploratory. No existing Roblox source, place file, or game UI was modified.

Open `index.html` for the numbered comparison board, followed by individual concept boards in order. Every individual board combines desktop and portrait-mobile dashboards with a component library, palette, typography and state examples.

## New directions

### 01 / STICKER CLUB

Expressive, collectible, and personal.

A polished sticker scrapbook UI: layered die-cut white label edges around individual cards, peeled sticker corners on selected tabs, irregular but tidy original collectible badge icons, washi-tape title label, subtle offset paper shadows. Coral, turquoise and lemon accents with dark ink. Brand mark is an original peel-corner rising-bar sticker. Navigation feels like collectible labels, account cards like neatly attached name tags. Controls have flat sticker shapes, NOT molded plastic, gel, neon or generic rounded SaaS cards. Pressed button loses its offset shadow; selected tab has a check-shaped sticker; disabled is faded with dashed edge; error quantity has a red annotation sticker. Original little doodles and badges in title/sidebar margins only; dense chart area perfectly plain. Headline is friendly chunky lettering; all body/data type clean modern sans. BUY forest with white text, SELL dark berry with white text.

- Palette: #FFF8EB, #202637, #F45C72, #83DDD2, #FEDB56, #196854
- Typography direction: Lilita One heading; DM Sans body and tabular numbers

### 02 / COMIC BOOK

Bold panels. Big personality.

Graphic comic-book page interface, confident 3px near-black outlines, slightly asymmetrical panel corners, white plotting surface, flat primary-color blocks, crisp hard offset ink shadows. Main dashboard geometry remains orderly and chart completely clean. Halftone dots ONLY in header, selected tabs and challenge card, never behind body text or data. Bold original comic lettering on headings, NOT body text; small original drawn shield/target/book icons. Notifications use speech-bubble tails in reserved space, error notification an exclamation bubble; modal is a large comic panel. BUY and SELL solid forest/berry with white text and outlines, no ambiguous color-only meaning. Pressed collapses ink shadow, selected gets double-ink underline/check, disabled ghosted with dashed outline, error field has expressive exclamation badge. No superhero IP or borrowed artwork, no childish characters, no neon or toy gloss.

- Palette: #FFFDF4, #202028, #F8CE3F, #528CDA, #197051, #B6314A
- Typography direction: Bangers heading; Atkinson Hyperlegible body and tabular numbers

Pressed state shows an inset pencil hatch at edge, disabled dotted outline. Headings use legible handwritten marker styling, every price/action/body label clear sans serif. ## States and accessibility targets

- **Default:** distinct resting button shape.
- **Pressed:** depressed, flattened, shifted or inset treatment appropriate to the material.
- **Selected:** persistent check, underline, pointer or tab marker as well as color.
- **Disabled:** visibly muted with an inactive/lock treatment; no activation in implementation.
- **Error:** outlined invalid quantity and “Enter at least 1” with an exclamation icon.

Keep all phone controls at least 48 × 48 logical pixels in implementation, including the hit regions around compact CLOSE labels. Allow 8px separation where possible. Essential controls and editable values should use readable type at least 16px in the actual mobile interface. These raster concepts are not measured or tested production controls.

Keep the simulation notice visible while content scrolls. Pair gains/losses with arrows, explicit words and signed values. Use filled up candles and hollow down candles with a legend. Chart labels, candles and numbers remain flat, clear and free of decorative effects.

Exact Roblox font availability, text metrics, responsive layouts, focus order and contrast should be verified after a direction is selected. Font specimens on these boards express the intended type direction.

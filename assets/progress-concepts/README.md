# Progress UI reference

`Progress UI Modules.rbxmx` is a historical native export of ProgressView and
TerminalUI from October 1, 2026. Keep it as a design reference; it is not the current
game implementation and should not be installed over current modules.

Current source is in `src/shared/ProgressView.luau` and
`src/shared/TerminalUI.luau` (repository-relative paths). Original milestone,
lock and checkmark artwork, prompts and Roblox IDs are in `assets/icons/progress/`.
Build the current place using the repository README and source manifest.

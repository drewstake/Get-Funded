Quick start in Studio

  1. Insert PolishedStatsPieces.rbxmx as a local model. Copy any named item from its Components folder into your UI.
  2. For the complete interactive example, place the imported folder under StarterPlayerScripts, enable Example, and press Play.
  3. Replace the example data provider with your server stats. The StatsPieces module handles the dropdown controls and editable values.

Native navigation reuses your existing game icon IDs. The offline SVG/PNG navigation icons are new vector reconstructions. See README.md for the asset map, data fields and API.

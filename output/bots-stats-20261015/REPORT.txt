Implemented /bots stats and installed both /bots stats and the previously staged /bots refresh
into Studio's editable Get Funded! place. Nothing was published. Save locally before closing.

Usage: owner types /bots stats, then presses Ctrl+C (Cmd+C on Mac).
The private report opens with its entire text preselected. Select report selects it again.
Mobile users can use native text selection/Copy. Roblox's supported in-experience clipboard
workflow requires the user copy gesture; this does not silently write the system clipboard.
Reference: https://create.roblox.com/docs/reference/engine/classes/TextBox

Report contents
- Total/active/retiring/depleted bot counts.
- Configured allocation, cash balance, equity, realized/unrealized/net P&L and capital adjustments.
- Positions/contracts, working and queued orders, pending exits and last refresh step.
- Tab-separated breakdowns by bot type and market, plus individual bot rows.
- All bot categories and retired-market obligations included; player/clearing/archive accounts excluded.
- Uses the new P&L baseline: prior profits and capital funding are not counted as new performance.

Security and state
- Existing creator/group-owner authorization runs before generating or sending a report.
- Server-to-owner FireClient only; no report-generating client remote handler or broadcast.
- Read-only, non-yielding snapshot; no simulation step, account/order changes or checkpoint write.
- Repeated callbacks are throttled. Oversized or failed reports return a private error notice.
- Reports are capped at 180,000 bytes; the captured 654-bot report was 78,640 bytes.
